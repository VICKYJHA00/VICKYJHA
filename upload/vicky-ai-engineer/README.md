# 🤖 Vicky AI Engineer

An AI engineering portfolio/workspace project. Built with TanStack Start, React, and TypeScript.

> Early-stage — currently a single-route (`index`) app. Update this README as features are added.

## 🛠️ Tech Stack

- **Framework:** TanStack Start (React)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, shadcn/ui, Radix UI
- **Deployment:** Cloudflare Workers (`wrangler`)
- **Package manager:** Bun

## 🚀 Getting Started

```bash
bun install
bun dev
```

## 📁 Project Structure

```
src/
├── routes/       # TanStack Router routes
├── components/   # UI components
├── data/         # Static/seed data
├── hooks/        # Custom React hooks
└── lib/          # Utilities
```

See also `DOCUMENTATION.md` and `COMPONENTS.md` in this repo for deeper technical notes.
